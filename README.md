What it does
CityDesk is an AI-powered voice input and dispatch assistant designed for non-emergency operators, such as 311 Toronto. It listens to resident calls in a natural manner, asks important and detailed follow up questions when information is missing, and translates the conversation into a detailed service request at efficient speeds.

How we built it
We built CityDesk as a web-based prototype combining a real-time AI voice interface with a dispatch dashboard.

The voice agent is powered by retell.ai, which allows CityDesk to take more than one call at a time, increase its efficiency in handling customer requests.

Using Vercel, we built the web application and connected the retell.ai voice interface to our dispatcher dashboard. The system takes each conversation and converts it into structured information, including the issue, location, priority, and recommended department, allowing real person dispatchers to quickly review and act on incoming requests.
